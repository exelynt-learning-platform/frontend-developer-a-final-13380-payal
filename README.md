Employee Management Application

A responsive Employee Management application built using Angular, NgRx, Bootstrap, and SCSS.

Features
Employee listing
Search employee by ID
Add employee
Edit employee
Delete employee with confirmation
Form validation
Country selection
Loading, error, and empty states
Responsive UI
NgRx state management
Unit tests
Technologies Used
Angular 19
TypeScript
NgRx
NgRx Entity
Bootstrap
SCSS
Angular Material
RxJS
